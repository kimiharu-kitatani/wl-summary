# YouTubeの「後で見る」を自動で要約一覧にした話（無料だけで構成）

「後で見る」に動画がたまり続けて、もう何が入っているのか分からない……。
そこで、**後で見るの動画を毎日自動で取り込み、日本語の要約つきで一覧表示するページ**を作りました。スマホでもPCでも見られて、使っているのは無料のサービスだけです。

## できること
- 後で見るの動画を、サムネイル・タイトル・チャンネル・**日本語の要約と要点**つきで一覧表示
- キーワード検索、チャンネル絞り込み、チャンネルごとのまとめ表示
- 並び替え：投稿日順 ／ 後で見るの並び順 ／ 自分でつけた★優先度順
- チェックボックスで選んで、**後で見るから一括削除**（PCのChromeのみ）
- 選んだ動画の「詳しい要約」をリクエスト

## 仕組み（全体像）
```
[PCのChrome拡張機能] ──毎日1回──▶ YouTube「後で見る」ページを読み取る
        │                          （ログイン中のブラウザの中で動く）
        ▼
[GitHubリポジトリ] data/wl.json（動画一覧）をコミット
        │
        ▼
[Bot] 字幕を取得（yt-dlp）→ 要約を作成 → summaries.json → build.py で data/data.json
        │
        ▼
[GitHub Pages] 静的なHTML1枚＋JSONで一覧表示（スマホ・PC）
```

## 作り方のステップ
1. **Chrome拡張機能（Manifest V3）**：後で見るページのデータ（ytInitialData）と、足りない分はスクロールで全件を集め、GitHubのAPIで `data/wl.json` をコミット。`chrome.alarms` で1日1回自動実行
2. **字幕と要約**：字幕は yt-dlp で取得してテキスト化。要約はBotが字幕を読んで日本語で書く（有料のAI APIは使っていません）
3. **ビューア**：`index.html` 1枚と `data.json` だけの静的ページ。GitHub Pagesで無料公開
4. **一括削除**：ページ上のボタン → 拡張機能に postMessage → 拡張機能がYouTubeのページ内で削除操作 → 一覧JSONも更新

## 使っているもの（すべて無料）
- Google Chrome の自作拡張機能（ストア公開なし・デベロッパーモードで読み込み）
- GitHub（リポジトリ＋Fine-grainedトークン＋GitHub Pages）
- yt-dlp（字幕・投稿日の取得）
- Python（データの結合スクリプト）

## ハマったところ・制限
- **YouTube Data API では「後で見る」を読めません。** 2016年以降、APIからは後で見るリストが空で返ります。なのでブラウザ拡張機能で、ログイン中のページから読み取る方式にしました
- 同じ理由で、APIからは後で見るの削除もできません → 拡張機能がページ上で操作します
- 「後で見るに追加した日」はページのデータに含まれていないため取得できません。代わりに**後で見るの並び順**で並べています（正直にそう表示しています）
- バックグラウンドのタブはChromeに処理を間引かれるので、読み込みが足りない時だけタブを一時的に前面にしています
- 字幕はYouTube側の保護で、ブラウザ内からの取得がうまくいかないことがあり、取得はBot側（yt-dlp）に任せています
- 無料のGitHub Pagesは公開リポジトリが前提なので、**一覧・字幕・要約は公開状態**になります。気になる人は注意

## 感想
たまっていた動画が「どれを見るべきか」一目で分かるようになり、見なくていい動画を一括で消せるようになって、後で見るがやっと整理できました。
